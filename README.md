# Eon for Teams

Static HTML presentation. No build step.

- Open `index.html`, or serve the folder with GitHub Pages (Settings > Pages > Deploy from branch, root).
- Navigate with arrow keys, space, click (right two-thirds = next), or swipe. `F` toggles fullscreen.
- Link to a slide with `#n`, e.g. `index.html#4`.
- Fonts load from Google Fonts (DM Sans). All images and videos are in `assets/`.
